# T-009 — Seed de demonstração

## Critério para revisão

Dado o banco de desenvolvimento vazio e as migrations aplicadas, quando o candidato roda `npm run seed`, então 57 anúncios `approved` do `backend/api-mock/seed/ads.json` são inseridos com UUID, `priceCents`, `createdAt` original e uma imagem placeholder do Picsum; quando roda de novo, o script recusa a base não vazia e não duplica. O arquivo do mock não é alterado e os 57 anúncios não passam pela moderação.

## Mudanças

- `scripts/seed.cjs`: lê o seed fornecido, exige tabela vazia, converte preços com `toCents`, insere em transação e usa placeholders `https://picsum.photos/seed/anuncio-{id}/640/480`.
- `package.json`: script `seed` (`npm run build && node scripts/seed.cjs`).
- README, DECISIONS e AI_USAGE documentam o uso e as decisões.
- O seed fornecido tem 57 anúncios, cinco categorias e nenhum `images`; o placeholder é a solução para a demonstração.

## Fora de escopo

Importar no startup, rodar o seed automaticamente na suíte, usar a moderação para os 57, alterar o mock ou o arquivo de seed, e popular o banco de desenvolvimento. O teste automatizado exercita a função `seedDatabase` (não o processo da CLI) em `anuncios_test`.
